Ein Gehäuse im PC-Stil aus Sperrholz und Plexiglas für den Raspberry Pi 5 mit Pimoroni-NVMe-Base und 40-mm-Lüfter.

## Gehäuse kaufen

- [Trainvent-Shop](https://trainvent.com/shop/raspberry-pi-5-case/)
- [Etsy](https://www.etsy.com/de-en/listing/1732482582/)

## Bevor du anfängst

Installiere Raspberry Pi OS Lite mit aktiviertem SSH. Fahre fort, sobald du dich von deinem Computer per SSH mit dem Pi verbinden kannst.
