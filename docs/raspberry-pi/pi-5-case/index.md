A PC-style case of plywood and plexiglass for the Raspberry Pi 5 with the Pimoroni NVMe Base and a 40 mm fan.

## Get the case

- [Trainvent Shop](https://trainvent.com/shop/raspberry-pi-5-case/)
- [Etsy](https://www.etsy.com/de-en/listing/1732482582/)

## Before you start

Install Raspberry Pi OS Lite with SSH enabled. Continue once you can reach the Pi over SSH from your computer.
